# 宿舍有线宽带

本科生宿舍提供家庭宽带服务，采用自建 FTTH（光纤到户）架构。

:::info[更新说明]
本节信息更新于 **2026-09-12**，来自社团群友提供。学校返修后网络架构已变化，宽带运营商已由联通切换至中国移动。
:::

## 硬件与接入

- **网口数量**：本科生宿舍配置四个网口，理论上可多人分别拉取宽带。
- **网线**：安装师傅可能会收走原有网线，换成新的网线。

## 认证与拨号

- **拨号方式**：现似乎需使用学号进行拨号认证。

## 运营商与套餐

中国移动校园宽带提供三档套餐。所有套餐均包含 80GB 蜂窝流量、200 分钟通话、120 CNY 教育超市权益或热门 APP 会员权益任选其一：

| 年费      | 宽带速率    |
| --------- | ----------- |
| 490 CNY   | 无家庭宽带  |
| 690 CNY起 | 300 Mbps 起 |
| 890 CNY   | 1000 Mbps   |

## 网络特性

- **网络类型**：自建 FTTH 校园宽带（家庭宽带）。
- **IPv6**：默认未配置，暂不清楚是否支持手动启用。
- **上传限制**：每月上传流量上限约 1 TB。
- **路由路径**：校内外流量可能分别走不同出口。学校似乎同时保留了移动和联通的出口链路。

## 测速参考

**测试环境**：1000 Mbps 套餐，非完全高峰时段

- **USTC 测速站**：延迟 32 ms，抖动 76.5 ms，下载 984 Mbps，上传 119 Mbps
- **Steam 下载实测**：约 800 Mbps 出头，无法完全跑满理论带宽

## 已知限制

- **校内外访问**：实验室工作站的校外公网 IP 暂无法直接访问校内资源。校内需通过 EasyConnect VPN（联通线路）访问校外资源。
