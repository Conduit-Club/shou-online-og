# 校园自助打印

:::warning[适用范围与时效]
本文记录上海海洋大学临港校区已知的自助打印设备。设备是否可用、收费标准、支持的文件格式及支付方式可能调整，请以设备屏幕和现场公示为准。最近核验日期：2026-09-13。
:::

## 已知位置

- **第一餐厅一楼：** ATM 机旁设有自助打印机。该位置也靠近平信与报刊收发室。

校学生会曾发布[《我为同学做实事｜嘿同学！校园新增打印机，你知道在哪里吗？》](https://mp.weixin.qq.com/s/0QhoBPAI7mtPc02_eUEwRQ)，说明校园内曾新增打印机。该通知为历史信息，其他设备的当前分布请以现场为准。

## 使用前确认

1. 先在设备屏幕或机身二维码处确认文件上传、登录和支付方式。
2. 提交前检查预览页数、单双面、彩色或黑白等选项，以及屏幕显示的费用。
3. 打印完成后及时取走文件，并退出账号或删除设备中暂存的文件。

:::tip[材料与隐私]
身份证、成绩单、证书等含个人信息的材料，建议只在现场操作和取件；如需复印，先确认原件是否遗留在扫描台。
:::

## 遇到问题

设备缺纸、卡纸、扣费后未出纸或无法登录时，请保留订单、支付或错误提示的截图，并按设备机身标注的客服或维护渠道反馈。现场没有标注联系方式时，可向第一餐厅服务台询问。
